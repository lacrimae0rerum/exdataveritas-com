ManifiestoManifesto

Lacrimae Rerum

Analista de Ciberinteligencia de Amenazas en un MSSP, trabajando en la intersección entre OSINT, investigación adversarial, apoyo DFIR, seguridad ofensiva y automatización para analistas.

Construyo herramientas local-first para trabajo de inteligencia: sistemas que ayudan a recopilar, estructurar, enriquecer y razonar sobre datos incompletos sin convertir cada flujo en una dependencia SaaS.

Áreas

  • CTIrecopilación, enriquecimiento, evaluación, reporting y contexto operativo.
  • OSINTinvestigación de superficie de ataque: infraestructura, validación de fuentes y correlación de entidades.
  • ToolingLLMs locales, integraciones MCP, Obsidian y automatización de tareas reales de analista.
  • Ofensivareconocimiento, laboratorios, emulación adversaria y sistemas de engaño.
  • GRCtraducción de hallazgos técnicos a lenguaje de riesgo útil para decisión ejecutiva.

Principios

  • Local-first antes que cloud-first.
  • Sistemas abiertos e inspeccionables antes que plataformas opacas.
  • Terminal cuando mejora la velocidad operativa.
  • IA para aumentar al analista, no para sustituirlo.
  • Disciplina de fuentes, calibración de confianza y análisis estructurado antes que acumulación de datos.

Stack

Python · TypeScript · Go · Shell · Docker · Linux · FastAPI · Svelte · SQLite · DuckDB · Obsidian · MCP · LLMs locales

Métodos y estándares

MITRE ATT&CK · Diamond Model · STIX/TAXII · TLP · técnicas analíticas estructuradas · fiabilidad de fuentes y scoring de confianza · contexto de reporting NIS2/DORA/ENS
